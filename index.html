First page: the honest scope note

This repository ships images only and contains no code, no installer, and no setting tool. It is a recolored derivative set for Kali Linux, credited to the upstream owerdogan collection, with added colours and extra wallpapers, distributed under the MIT License as stated in its LICENSE file. Choosing a file means downloading the image and setting it by whatever method you already use on your own system.

Every image in the set is in 16 by 9 form: the single aspect ratio note on this site, kept in sky blue as the prompt book keeps it.

Third page: the recurring designs

The designs recur across folders, named as the files name them: the plain colour base, abstract sky and its dark variant, ascii, contours, dark, geometric and geometric extras, light strips, logo, mesh, neon and neon extras, and nova.

Not every folder holds every design. Blue, grey, orange, pink, and purple hold fifteen files each; cyan, green, red, and yellow hold fourteen; black holds twelve; white holds only nine, with no plain abstract sky, no light strips, no logo, no mesh, and no nova file in the tree.

Fourth page: file notes, credit, and licence

Formats mix PNG and JPG from folder to folder, and file sizes vary a great deal. Some nova and contours files run to many megabytes, so a slow connection warning sits beside those thumbnails above.
