Wallpapers-For-Kali-2025

This project added some colours and extra wallpapers: the Kali Linux wallpaper set recolored into eleven colour folders, plus an extras folder holding two additional images. The same designs go into every vat and come up a different colour each time, 154 images in all.

Open the repo The eleven colours

Credit and scope

Credit to owerdogan for the upstream wallpaper set. Scope note, stated plainly in the repo: this is a recolored derivative of that upstream set, not original Kali artwork. Each colour folder holds one recolor set, and the extras folder holds two additional images. The repo ships images only: there is no code, no installer, and no setting tool in it.

The eleven colours

Every folder recolors the same family of designs: abstract sky, ascii, contours, dark, geometric, logo, mesh, neon, nova, light strips, and their extras variants. The sets are not all the same size:

15 imagesblue, grey, orange, pink, purple
14 imagescyan, green, red, yellow
12 imagesblack
9 imageswhite, which holds nine files only, with no plain abstract sky, no light strips, no logo, no mesh, and no nova file
Extras2 images: an inverted ascii extras and an amethyst geometric extras

How the sets read

The README lays the collection out folder by folder, each colour behind its own fold with every image at reading width: pick a colour, open its fold, and the whole set is there. The artwork on this page is the dye workshop the recolors suggest: one pale length of linen, a row of oak vats, and the cloth coming up slate, grey, and brightest of all in scarlet.
